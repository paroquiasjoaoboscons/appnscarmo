Gerenciar Fotos e Vídeos da Pascom

Para que as fotos e vídeos apareçam no aplicativo, a equipe da Pascom deve subir os arquivos no GitHub seguindo as regras abaixo.

📸 8 Fotos

As fotos devem ser no formato JPG e ter no máximo 300 KB cada.

Os nomes devem ser exatamente:

  • foto1.jpg até foto8.jpg

Atenção: Não use letras maiúsculas, acentos ou espaços nos nomes.

🎥 2 Vídeos

Os vídeos devem ser no formato MP4.

Os nomes devem ser exatamente:

  • video1.mp4 e video2.mp4
Abrir Página de Upload no GitHub

O link abrirá a pasta do projeto no GitHub para envio dos arquivos.
